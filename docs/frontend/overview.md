# Страница «Обзор»

Главная мониторинговая страница ODYSSEY.

## Структура

- **Состояние кластера** — сводные KPI и таблица брокеров с внутренней прокруткой.
- **Сертификаты Kafka** — табличный список сертификатов и сроков действия.
- **Пропускная способность кластера** — входящий и исходящий поток сообщений.
- **Пропускная способность по топикам** — график, текущее и максимальное значение каждого активного топика.
- **Группы потребителей** — график лага и таблица групп с внутренней прокруткой.
- **Последние события** — события Kafka с фильтром уровня и внутренней прокруткой.

## Поведение

- При смене кластера старые данные не используются для нового bootstrap.
- Автообновление данных не меняет состояние доступности кластера.
- Доступность Kafka контролируется на уровне общего Layout.
- Настройки и Пользователь доступны независимо от состояния Kafka-кластера.
- Увеличение панели открывает её в центрированном модальном режиме с размытым фоном.

## Стили

Все стили страницы находятся в `src/pages/overview/styles/` и используют CSS-переменные тем ODYSSEY.
