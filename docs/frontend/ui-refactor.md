# Frontend — ODYSSEY 4.2.6 UI Refactor

## Основные изменения

- единая горизонтальная Page Header для всех страниц;
- название и краткое описание страницы находятся в общей шапке;
- период и автообновление доступны только мониторинговым страницам;
- период поддерживает быстрые диапазоны и абсолютные дату/время;
- интервалы обновления: Off, 5s, 10s, 30s, 1m, 5m, 15m, 30m, 1h, 1d;
- при загрузке по нижней границе шапки проходит небесно-голубая волна;
- Overview переработан в единую Conduktor/Grafana-подобную сетку;
- KPI встроены в «Состояние кластера»;
- Consumer / Producer rate объединены;
- добавлена панель сертификатов;
- добавлен полноэкранный просмотр панелей;
- недоступный выбранный кластер отображается отдельным экраном;
- стартовый splash screen восстановлен;
- полосы прокрутки используют цвета активной темы.

## Структура Overview

Специфичные компоненты страницы находятся в:

`src/pages/overview/components/`

Описание структуры находится в `src/pages/overview/DESCRIPTION.md`.

## TypeScript

Все новые и переработанные элементы этой задачи реализованы в TS/TSX.
Не относящиеся к задаче старые JSX-файлы других страниц не переписывались
массово, чтобы не смешивать UI-рефакторинг с полной миграцией проекта.
