# Быстрый старт

Odyssey v4.3.2 требует локально созданного владельца установки, приватного
серверного хранилища и отдельного ключа шифрования. При Docker-развёртывании
используется HTTPS как для браузера, так и между Nginx и backend.

Следуйте [инструкции первого запуска Docker](docker-owner.md):

1. Настройте точный публичный origin и разрешённые Kafka-адреса/порты.
2. Соберите образы и подготовьте приватные тома.
3. Выполните интерактивный `owner-init`, затем настройте доверие к CA.
4. Запустите frontend; backend стартует как зависимость с TLS healthcheck.
5. Откройте `https://localhost:8443` и войдите владельцем.

При обновлении сначала прочитайте [порядок миграции](security-owner-migration.md).
Не удаляйте localStorage или существующие тома, не создавайте новый ключ
вместо потерянного. Смена схемы/порта браузера сама по себе профили не переносит.

Для подключения используются Kafka Bootstrap Servers, а не ZooKeeper. Поддерживаются Kafka 3.x в режиме ZooKeeper и Kafka 4.x в режиме KRaft; доступность метрик зависит от версии и прав.

Старые профили с полем `zookeeper` обрабатываются защищённой миграцией владельца. Поле не редактируется и не передаётся в REST-конфигурацию Kafka.
