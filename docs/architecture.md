# Архитектура

React и Vite обслуживают интерфейс. Go backend принимает REST-запросы и использует IBM Sarama для мониторинга и административных операций Kafka. Полномочия владельца Odyssey дополняют проверки Kafka ACL.

Core поддерживает одного локального владельца, серверные сессии, CSRF-защиту, зашифрованные серверные Kafka-профили и политику исходящих адресов. Ключ хранится отдельно. В Docker Nginx завершает TLS браузера и проверяет сертификат Go backend при проксировании API.

Публичная сборка содержит Core и контракт расширения `@odyssey/registry`. Публичный реестр Enterprise пуст. Модули Enterprise распространяются отдельно.
