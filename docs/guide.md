# Руководство пользователя

## Подключения

Профили используют Kafka Bootstrap Servers, включая несколько адресов, и доступны владельцу после входа. Kafka 3.x с ZooKeeper подключается через Kafka-протокол. Kafka 4.x использует KRaft. Для подключения доступны PLAINTEXT, mTLS и SASL поверх TLS с механизмами PLAIN и SCRAM-SHA-256/512. GSSAPI временно отключён. Для SASL через TLS используйте соответствующий listener Kafka и доверенную CA-цепочку.

## Страницы

| Страница | Возможности |
| --- | --- |
| Обзор | KPI, брокеры, сертификаты, пропускная способность, группы потребителей и события. |
| Брокеры | Адреса и доступные данные о брокерах. В развёрнутой панели Обзора есть карточки, список, поиск и фильтры. |
| Топики | Список топиков, партиции и конфигурация. Изменения требуют полномочий владельца и Kafka ACL. |
| Группы потребителей | Состояние групп, участники, offsets и lag при наличии данных. |
| Поиск | Чтение сообщений из выбранного топика с параметрами поиска. |
| ACL | Просмотр и управление правилами Kafka при наличии соответствующих прав брокера. |

[Обзор](frontend/overview.md) и [структура Consumer Groups](frontend/consumer-groups.md) описаны отдельно.

## Метрики и ограничения

Odyssey получает данные через Kafka-протокол и показывает то, что удалось подтвердить. Пропускная способность рассчитывается по наблюдаемым изменениям Kafka offsets. Статус unknown означает отсутствие достаточного подтверждения доступности. Диск, версия Kafka и роли контроллеров отображаются при наличии данных. CPU, RAM и время непрерывной работы кластера могут быть недоступны. Н/Д означает отсутствие данных.

## Настройки и диагностика

В Settings доступны темы, язык и проверка новых версий. В Docker раздел HTTPS показывает сертификат и команды локальной замены или перевыпуска. Обновляйте контейнеры по инструкции выпуска с сохранением томов.

Если Kafka недоступна, проверьте серверный список адресов и портов, `advertised.listeners`, соответствие протокола listener, CA и права Kafka. При ошибке миграции сохраняйте исходный профиль браузера до проверки серверной копии.
